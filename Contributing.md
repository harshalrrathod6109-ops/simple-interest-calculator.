# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your change:
   `git checkout -b my-feature`
3. Make your changes and commit them:
   `git commit -m "Describe your change"`
4. Push the branch to your fork:
   `git push origin my-feature`
5. Open a pull request so your changes can be reviewed.

## Reporting Bugs

Open an issue and describe the problem, the steps to reproduce it, and what you expected to happen.

## Suggesting Enhancements

Open an issue describing your idea and how it would improve the project.

## Code of Conduct

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
